# Project Memory Skill — LegendPrix AI Web App

- What already exists in this static showcase web application (`legendprixai.lol`).

- The 4 flagship products (MacMint, TopBump, DotMesh, TinyOrbit URL) and their dedicated detail pages (`macmint.html`, `topbump.html`, `dotmesh.html`, `tinyorbiturl.html`).
- The strict 100% static hosting compatibility requirement for GitHub Pages (no Node server or server-side rendering).
- Why `prd.md` and `design.md` must not be overwritten without explicit requirement changes.
