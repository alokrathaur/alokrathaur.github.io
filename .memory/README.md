# LegendPrix AI Web App — Engineering Memory

This directory acts as the persistent engineering memory for **LegendPrix AI Web App**, the official web portal for digital product studio LegendPrix AI (`legendprixai.lol`).

## Source of Truth Hierarchy
1. **PRODUCT / DESIGN INTENT**: `prd.md`, `design.md`, `skills.md`, `Brand Identity Presentation-LegendPrix.png`
2. **PROJECT MEMORY**: `.memory/`
3. **CURRENT IMPLEMENTATION**: Source code (`index.html`, `macmint.html`, `topbump.html`, `dotmesh.html`, `tinyorbiturl.html`, `css/`, `js/`)

## Documentation Protection Rule
Do NOT automatically alter `prd.md` or `design.md` when code differs. Record implementation gaps in `.memory/REQUIREMENTS.md` and `.memory/CURRENT_STATE.md`.
