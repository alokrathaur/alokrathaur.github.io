# Project Metadata — LegendPrix AI Web App

- **Project Name**: LegendPrix AI Web App
- **Domain**: `https://legendprixai.lol` (configured via CNAME on GitHub Pages repo `alokrathaur.github.io`).
- **Description**: Elite digital product studio portal dedicated to transforming "Ideas into Products" across Web Apps, Mobile Apps, and SaaS.
- **Studio Mission**: "A product studio for a brighter digital world."
- **Studio Slogan**: "Ideas into Products."
- **Four Methodological Pillars**:
  1. **IDEA**: Identifying user friction and conceptualizing ambitious digital solutions.
  2. **BUILD**: Rapid prototyping, robust architecture, and pixel-perfect engineering.
  3. **PRODUCT**: Intuitive UX, high reliability, and polished tactile interfaces.
  4. **GROWTH**: Data-driven scaling, user acquisition, and iterative product evolution.
- **Technology Stack**:
  - HTML5 (semantic structure, high SEO score).
  - Vanilla CSS3 (shadcn-inspired dark palette, glassmorphism, responsive grid).

- **Repository Structure**:
  - `index.html`: Studio homepage with 3D hero globe and flagship product showcase.
  - `macmint.html`: MacMint dedicated product showcase page.
  - `topbump.html`: TopBump dedicated product showcase page.
